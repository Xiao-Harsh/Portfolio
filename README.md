# 👨‍💻 Harsh Kumar's Portfolio

My personal portfolio website to showcase my projects, skills, and journey as a B.Tech Computer Science student. It is built using pure HTML, CSS, and vanilla JavaScript (no external libraries or frameworks).

* **Live Link:** [xiao-harsh.github.io/Portfolio/](https://xiao-harsh.github.io/Portfolio/)
* **Resume:** [Resume.pdf](./Resume.pdf)

---

## ✨ Features

* **Custom Cursor:** A smooth dual-circle mouse pointer animation with GPU acceleration (`translate3d`).
* **Dark/Light Mode:** Theme toggle with `localStorage` persistence and fallback support.
* **Instant Skills Filtering:** Category-based filter system (Languages, Web, Database, Tools) with instant, synchronous UI updates.
* **Interactive Project Details Modals:** Dynamic modal popups providing deep architectural breakdowns for every featured project.
* **Responsive Contact Section:** Single-line fluid email scaling (`white-space: nowrap`) and a 2×3 social icon grid optimized across all mobile viewports.
* **AJAX Contact Form:** A modal form connected to the Web3Forms API to send messages seamlessly without page reloads.

## 💻 How to Run Locally

Since this is a vanilla web project, you can run it without any manual dependency installations:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Xiao-Harsh/Portfolio.git
   ```
2. **Go to the project directory:**
   ```bash
   cd Portfolio
   ```
3. **Start a local dev server with Node / NPX:**
   ```bash
   npx serve
   ```
   *Alternatively, you can open `index.html` directly in any web browser or use VS Code Live Server.*
